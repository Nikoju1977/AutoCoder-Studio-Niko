Dans Autopilot, choisir un profil graphique, autoriser les appels Agnes et démarrer. Les six profils partagent les quatre agents existants et le budget maximum de 12 appels par lot. Chaque profil possède son propre curseur. Seuls les petits fichiers HTML/CSS déjà admissibles sont sélectionnés (trois maximum); pas de JavaScript, framework ajouté, dépôts privés ou sensibles. Les grands fichiers et applications sans fichiers admissibles nécessitent un traitement manuel. Un contrôle lexical conservateur bloque certains changements de contrats HTML et de ressources CSS; il ne garantit ni sécurité ni accessibilité. Toute proposition reste soumise à revue humaine, tests navigateur et validation avant fusion. Les quotas Agnes restent applicables. ## UI Engine Pro V2 — preuve visuelle locale

Les tokens proposés (espacements, rayons, mouvement) constituent une convention, pas un design system déjà déployé. Après accord, exporter le dossier de preuve (HTML requis). Dans un clone AutoCoder, lancer npm ci, npx playwright install chromium, puis npm run ui:visual -- /chemin/niko-ui-visual.json. Le rapport donne un dossier temporaire avec six PNG (360, 768, 1440 px, avant/après) et report.json. Chromium travaille sur les fichiers sélectionnés uniquement, sans scripts de projet, sans réseau externe et sans ressources non incluses. Les régressions de débordement, visibilité, petites cibles et noms apparents sont signalées ; code de sortie 1 si régression. Ce rapport ne prouve ni la conformité WCAG, ni les performances runtime, ni le bon fonctionnement métier. Aucun rejet automatique dans la passerelle ni publication : joindre le rapport à la revue et effectuer les tests applicatifs. Le test E2E CI utilise une fixture, non les dépôts Studio Niko réels.

## UI Engine Pro V3 — Design Intelligence

Copier les classes choisies sans remplacer les identifiants fonctionnels. L'audit détecte désormais les contrastes simples (texte sur fonds opaques, seuils 4,5:1 et 3:1 selon taille), avec compteurs de cas non mesurés; ce n'est pas un audit WCAG complet. Les ordres de tabulation positifs sont signalés. `npm run ui:repair -- /chemin/niko-ui-visual.json` tente uniquement une correction de taille des boutons natifs dans une feuille CSS déjà modifiée et unique. Le moteur compare les captures avant/après, rejette les nouvelles régressions mesurées et exporte un candidat local uniquement si une amélioration est observée sans régression mesurée par rapport à l'original. Les applications et les dépôts ne sont jamais modifiés automatiquement. Aucun nouveau fournisseur, aucun appel réseau supplémentaire. Les guides Modern Web Guidance n'ont pas été récupérés dans cette session; tests et revue manuelle requis.
