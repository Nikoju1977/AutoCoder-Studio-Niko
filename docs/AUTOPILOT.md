## UI Engine Pro V1
Dans Autopilot, choisir un profil graphique, autoriser les appels Agnes et démarrer. Les six profils partagent les quatre agents existants et le budget maximum de 12 appels par lot. Chaque profil possède son propre curseur. Seuls les petits fichiers HTML/CSS déjà admissibles sont sélectionnés (trois maximum); pas de JavaScript, framework ajouté, dépôts privés ou sensibles. Les grands fichiers et applications sans fichiers admissibles nécessitent un traitement manuel. Un contrôle lexical conservateur bloque certains changements de contrats HTML et de ressources CSS; il ne garantit ni sécurité ni accessibilité. Toute proposition reste soumise à revue humaine, tests navigateur et validation avant fusion. Les quotas Agnes restent applicables. Aucun rendu visuel ni test réel n'est exécuté par les agents eux-mêmes.

## UI Engine Pro V2 — preuve visuelle locale
Le mode Auto choisit un profil par mots-clés du nom et de la description publique, sans appel supplémentaire. Les tokens proposés (espacements, rayons, mouvement) constituent une convention, pas un design system déjà déployé. Après accord, exporter le dossier de preuve (HTML requis). Dans un clone AutoCoder, lancer npm ci, npx playwright install chromium, puis npm run ui:visual -- /chemin/niko-ui-visual.json. Le rapport donne un dossier temporaire avec six PNG (360, 768, 1440 px, avant/après) et report.json. Chromium travaille sur les fichiers sélectionnés uniquement, sans scripts de projet, sans réseau externe et sans ressources non incluses. Les régressions de débordement, visibilité, petites cibles et noms apparents sont signalées ; code de sortie 1 si régression. Ce rapport ne prouve ni la conformité WCAG, ni les performances runtime, ni le bon fonctionnement métier. Aucun rejet automatique dans la passerelle ni publication : joindre le rapport à la revue et effectuer les tests applicatifs. Le test E2E CI utilise une fixture, non les dépôts Studio Niko réels.

## UI Engine Pro V3 — Design Intelligence
La bibliothèque opt-in `niko-ui.css` et `ui-library.html` proposent des cartes, commandes, formulaires, indicateurs, barre d'outils et timeline statique. Copier les classes choisies sans remplacer les identifiants fonctionnels. L'audit détecte désormais les contrastes simples (texte sur fonds opaques, seuils 4,5:1 et 3:1 selon taille), avec compteurs de cas non mesurés; ce n'est pas un audit WCAG complet. Les ordres de tabulation positifs sont signalés. `npm run ui:repair -- /chemin/niko-ui-visual.json` tente uniquement une correction de taille des boutons natifs dans une feuille CSS déjà modifiée et unique. Le moteur compare les captures avant/après, rejette les nouvelles régressions mesurées et exporte un candidat local uniquement si une amélioration est observée sans régression mesurée par rapport à l'original. Les applications et les dépôts ne sont jamais modifiés automatiquement. Aucun nouveau fournisseur, aucun appel réseau supplémentaire. Les guides Modern Web Guidance n'ont pas été récupérés dans cette session; tests et revue manuelle requis.

## UI Engine Pro V4 — comparaison et accessibilité
Le rapport local génère trois PNG supplémentaires diff-*.png et mesure les pixels différents (seuil de 16 niveaux par canal; différence exacte aussi comptée). Ce taux ne mesure pas la qualité esthétique. axe-core 4.10.3, dépendance de développement épinglée, est injecté par Playwright dans le document statique, sans activer les scripts du projet. Les violations et cas incomplets des règles WCAG 2.0/2.1 A/AA sont comptés; les nouvelles violations bloquent la correction automatique, qui exige une mesure axe complète avant/après. Cela ne constitue pas une certification. La réparation tente deux variantes bornées (24 puis 44 px si rejet), sans publication, et conserve les preuves. La galerie ajoute des pistes, commandes de transport illustratives et inspecteur 3D; aucun moteur métier n'est fourni par ces composants. Pas de transmission d'images au fournisseur IA: le contrat Agnes actuel est textuel et sa compatibilité vision n'est pas vérifiée. Installation npm ci et validation CI indispensables; le registre npm et Modern Web Guidance n'étaient pas accessibles depuis l'environnement local de cette intervention. L'intégrité axe-core est reprise de lockfiles publics concordants et doit être vérifiée par npm ci.

## UI Engine Pro V5 — Design Factory
Ouvrir ui-factory.html depuis Autopilot ou la bibliothèque. Éditeur WYSIWYG de thèmes (pas de refonte arbitraire du DOM d'un dépôt): six palettes prédéfinies, couleurs, espacement, arrondis, durée de transition, deux variantes indépendantes, comparaison de huit ratios de contraste, aperçu local et responsive. Enregistrement explicite des deux variantes dans localStorage; import JSON borné et validé; export du CSS à charger après niko-ui.css sur un conteneur .niko-ui.niko-custom, et JSON réimportable. Les commandes de démonstration ne pilotent aucun moteur métier. Les profils ne sont pas déployés automatiquement sur la flotte. Pas de nouvel agent ni appel réseau; le critique existant reçoit une consigne de cohérence graphique. L'intégration au Hub et le moteur de refonte complète restent à faire après validation. Correctif V4: audit axe borné dans le temps, moteur JS disponible pour DevTools, mais scripts projet interdits par CSP HTTP et routage; tests de non-exécution à vérifier. Les guides Modern Web Guidance n'ont pas été récupérés durant cette intervention.
