Guide rapide

Générer : entre une demande. Le mode local utilise des modèles Python et web ; le mode IA requiert un serveur configuré.

Éditer : clique un fichier, puis modifie son contenu. Sauvegarde automatique locale.

Exécuter : lance un fichier Python via Pyodide (chargement Internet la première fois).

Tests : lance les tests Python du fichier test_main.py si présent.

Site web : clique « Aperçu » pour afficher index.html dans une iframe isolée.

Exporter : télécharge un fichier JSON contenant tous les fichiers du projet.

IA : les réglages permettent d'activer une API protégée, hébergée sur ton serveur. Aucune clé fournisseur n'est enregistrée dans le navigateur.

Limites : aucun push GitHub ou déploiement Vercel automatique dans cette version.
