08 / AutoPublish — revue GitHub

Après comparaison, télécharger la proposition GitHub. Publication depuis un terminal Node local uniquement, avec un jeton GitHub limité aux dépôts choisis, configuré dans l’environnement CMX_GITHUB_TOKEN. Ne jamais coller ce jeton dans l’interface ni dans GitHub.

node scripts/publish.mjs proposition.json
node scripts/publish.mjs proposition.json --publish SHA256_AFFICHE

La première commande ne fait que lire GitHub. La seconde exige le SHA-256 exact de la proposition approuvée, vérifie le commit source et crée une branche neuve avec une Pull Request brouillon. Aucun merge automatique. Relire le code et vérifier les risques liés aux workflows CI avant de publier.

Documentation complète
